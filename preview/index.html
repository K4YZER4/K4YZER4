PDF Filler

Payroll credit contract automation backend: multimodal AI document extraction, financial calculation, AcroForm PDF generation, remote signing, and RBAC control desk.

 

Repositories: Backend (NestJS) · Frontend

FieldDetails
AuthorHoracio Alvarez Escobedo
StatusDEMO LIVE
Live Demopdf-filler.k4yzer4.dev
StackNestJS · TypeScript · Prisma · PostgreSQL · Gemini AI · Zod · pdf-lib · Cloudinary · Docker

01 / Overview

End-to-end backend system built to automate payroll credit contract workflows—from extracting client data out of identity and income documents with multimodal AI, to computing amortization tables, generating filled multi-page AcroForm PDFs, and managing secure remote signing with role-based auditing.

02 / Architecture & Engineering Highlights

#AreaImplementation Details
01Multimodal AI Document ExtractionUnified INE, payroll stub, and bank statement OCR via Google Gemini AI with Zod schema validation and CURP verification.
02Credit Table & Multi-Page PDF EngineAmortization and CAT calculation from Excel tables (exceljs), AcroForm filling (pdf-lib), and handwritten signature stamping stored in Cloudinary.
03Secure Remote Signing FlowExpiring one-time signing links (TokenFirma), optional 6-digit OTP verification, and an anti-SSRF PDF proxy blocking private IP ranges.
04Control Desk RBAC & Production HardeningJWT auth with ASESOR/ADMIN roles, PostgreSQL trigger-backed state machine and audit history, token-bucket rate limiting, Helmet, and pino logs.

03 / Live Demo Notes

Runs in public DEMO_MODE with an anonymized contract template (contrato_demo.pdf) and optional visitor X-Gemini-Api-Key.

LoL Party

Real-time multiplayer minigame platform (9 minigames in a deterministic engine) powered by authoritative WebSockets, room locking, and typed monorepo contracts.

 

Repository: Monorepo (GitHub)

FieldDetails
AuthorHoracio Alvarez Escobedo
StatusDEMO LIVE
Case Study & Demolol-party.k4yzer4.dev/portafolio
StackNestJS · Socket.IO · TypeScript · Node.js · Zod · Cloudflare R2 · Docker

01 / Overview

Authoritative real-time multiplayer platform hosting 9 synchronized minigames inside a deterministic, server-driven engine. Built as a strictly typed monorepo with shared runtime contracts, anti-cheat media proxying, and automated unit and end-to-end test suites.

02 / Architecture & Engineering Highlights

#AreaImplementation Details
01Authoritative Real-Time GatewayNestJS 12 + Socket.IO server using per-room locking (withRoomLock) against race conditions, token reconnection, and bounce-free host handover.
02Deterministic Game Engine (packages/engine)9 minigames written as pure functions with seeded PRNG, 250ms server tick, and strict public/private state projection per player.
03Anti-Cheat Proxy & Network SecurityOpaque media proxy for ability icons and audio clips so answers never leak in DevTools, tiered rate limiting, and Cloudflare IP validation.
04End-to-End Contracts & Automated TestsShared Zod 4 schemas in packages/protocol, 74+ automated unit tests, and a 43-check real-server E2E suite.

03 / Live Demo Notes

The portfolio page includes a full architecture walkthrough, demo video, and direct access to launch private multiplayer rooms.

RITMO

Training platform backend and PWA connecting trainers and athletes through workout routines, set/PR tracking, one-time linking tokens, and Stripe subscriptions.

 

Repositories: Repository (GitHub) · Deploy Infra (Docker + Nginx)

FieldDetails
AuthorHoracio Alvarez Escobedo
StatusDEMO LIVE
Live Demoritmo.k4yzer4.dev
StackNestJS · TypeScript · Prisma · PostgreSQL · Stripe · Zod · Jest · Docker · Nginx

01 / Overview

Full-stack training platform and PWA connecting coaches and athletes with structured workout routines, session logging, automatic personal record (PR) tracking, single-use coach-athlete linking tokens, and Stripe subscription billing.

02 / Architecture & Engineering Highlights

#AreaImplementation Details
01Multi-Schema PostgreSQL ArchitectureRelational model with Prisma 7 organized across 5 PostgreSQL schemas (core, app_user, entrenador, alumno, ubi) and versioned migrations.
02Training Domain & Automatic PR TrackingRoutine scheduling with date-overlap resolution, plan-limited custom exercises, session logging, and automatic personal record calculation.
03Authentication & One-Time LinkingGlobal JWT guard (@Public / @CurrentUser), expiring single-use trainer-to-student linking tokens, and strict Zod environment validation.
04Stripe Subscriptions & Multistage DeployStripe Checkout plus idempotent webhooks with event deduplication; deployed via Vercel and a multistage Docker + Nginx proxy on Render.
